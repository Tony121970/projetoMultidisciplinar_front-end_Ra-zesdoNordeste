# Raízes do Nordeste

## Do Projeto
<h1><font weight="normal">&emsp;O "Raízes do Nordeste" é um projeto acadêmico multidisciplinar desenvolvido com o objetivo de testar todo o conhecimento adquirido pelo aluno ao longo do curso.</font></h1>

<h1><font weight="normal">&emsp;O objetivo geral era desenvolver uma interface front-end (com APP) funcional capaz de conectar os diferentes setores do restaurante e de suas filiais em tempo real, utilizando tecnologias de desenvolvimento web e recursos para disponibilização da aplicação também como aplicativo. O sistema foi projetado para atender de forma personalizada a diversos perfis de usuários, cada um com necessidades e níveis de acesso específicos. Na ponta inicial do processo, estão os clientes, que utilizam o sistema para navegar e realizar seus pedidos de forma autônoma. Na operação diária, os atendentes gerenciam as interações iniciais, enquanto a equipe da cozinha visualiza imediatamente a fila de produção para preparar os pratos. Por fim, o setor de entrega assume a distribuição dos pedidos e a gerência, junto à área administrativa, monitora relatórios financeiros e o desempenho geral do negócio. Cobrir desde o acesso ao site pelo usuário até a finalização da entrega e coleta de feedback. Tudo isso, de forma clara, rápida e objetiva, fazendo com que o usuário do site seja tratado não apenas como um cliente, e sim como um parceiro da rede. Esse é o principal objetivo do projeto.</font></h1>
